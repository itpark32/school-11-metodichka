# Функция как значение, lambda и генераторы коллекций

!!! abstract "Фокус"
    - **Нужно знать:** передача функции, lambda, list/dict/set comprehension и генераторное выражение.
    - **Нужно уметь:** прочитать краткую запись и развернуть её в обычный цикл.

## Теория

Функцию можно сохранить в переменную, передать другой функции и вызвать позже. Именно так работают key в сортировке и фильтры обработчиков бота. Передача функции без скобок отличается от передачи результата её вызова.

### Lambda — выражение-функция

```python
def apply(value, action):
    return action(value)
print(apply(150, lambda price: price * 2))
```

Lambda получает параметры и возвращает одно выражение. Не нужно писать return. Для ветвления с несколькими шагами, журналом и проверками обычная def понятнее. Краткость не должна скрывать правило.

### Генератор списка

```python
prices = [100, 300, 50]
available = [price for price in prices if price <= 100]
```

Читайте справа налево по ролям: из prices берём price, проверяем if, добавляем выражение слева от for. Результат — новый готовый список. Такой синтаксис часто называют «генератором списка», но это не ленивый генератор.

### Словарь и множество

`{item["id"]: item for item in items}` строит словарь. Если ID повторяется, поздняя запись заменит раннюю: это не проверка уникальности. `{item["category"] for item in items}` строит множество уникальных категорий; порядок для показа задайте отдельно.

### Генераторное выражение

```python
values = (price * 2 for price in prices)
print(sum(values))
```

Круглые скобки создают ленивый источник элементов: он выдаёт значения по мере перебора. Повторный проход по уже исчерпанному генератору не возвращает значения заново. Для нескольких проходов храните список или создавайте новое выражение.

### Когда вернуться к циклу

Если внутри появляется обработка нескольких ошибок, сложные вложенные условия или несколько изменений состояния, выберите обычный for. У генератора коллекции должна быть одна читаемая идея: отобрать и преобразовать.

## Частые ошибки

Не путайте list comprehension с ленивым генератором. Не передавайте результат вызова вместо функции для key. Генератор словаря не обнаруживает дубли ключей.

## Разбор практических задач

Сначала запишите свой план и ожидаемый результат, затем сравните с разбором.

### Задача 1. Ключ сортировки

#### Условие

Упорядочьте услуги по цене с помощью переданной функции.

#### Как рассуждать и алгоритм

Lambda возвращает цену одной записи, sorted использует её как ключ.

#### Решение

```python
items = [{"name": "A", "price": 300}, {"name": "B", "price": 100}]
print(sorted(items, key=lambda item: item["price"]))
```

#### Проверка

B идёт раньше A. Печать списка не изменяет основной порядок.

### Задача 2. Отбор и преобразование

#### Условие

Получите названия доступных услуг из каталога.

#### Как рассуждать и алгоритм

Условие отбирает записи, выражение слева извлекает название.

#### Решение

```python
items = [{"name": "A", "stock": 0}, {"name": "B", "stock": 3}]
names = [item["name"] for item in items if item["stock"] > 0]
print(names)
```

#### Проверка

Только B. Сначала разверните выражение в цикл append и сравните результат.

### Задача 3. Один проход

#### Условие

Покажите, что генератор после sum исчерпан.

#### Как рассуждать и алгоритм

Первый потребитель перебирает значения, второй уже не получает их.

#### Решение

```python
amounts = (value for value in [100, 200])
print(sum(amounts))
print(list(amounts))
```

#### Проверка

300, затем []. Если нужен повторный просмотр, заранее создайте список.
