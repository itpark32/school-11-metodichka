# CRUD, стабильные ID и изменение каталога

<p class="reading-time">Примерное время · Чтение: 5–7 мин · Практика: 45–75 мин</p>

!!! abstract "Фокус"
    - **Нужно знать:** Create, Read, Update, Delete, ID, None и результат отказа.
    - **Нужно уметь:** реализовать операции без меню и сохранить данные при неуспехе.

## Теория

CRUD — четыре операции над записями: создать, прочитать, изменить и удалить. Они нужны каталогу услуг, журналу заявок и списку клиентов. Консоль и Telegram — способы вызвать эти операции, а не место хранения их правил.

### Общая модель для примеров

```python
from dataclasses import dataclass
@dataclass
class Product:
    id: int
    name: str
    stock: int
```

Каталог — list[Product]. Поиск возвращает объект либо None; вывод делает UI. Обновление и удаление сообщают, нашли ли запись. Нет результата — нормальный исход поиска, а не обязательно исключение.

### ID остаётся прежним

Если список содержит ID 10 и 30, их индексы 0 и 1. Удаление первого сдвинет индекс второго, но ID 30 останется. Нельзя выдавать новый ID как len(products)+1: после удаления он может повториться. Используйте отдельный последний выданный ID, сохраняйте его с каталогом и восстанавливайте при старте.

### Изменение по договору

До операции определите, что она получает, возвращает и меняет. Для обновления сначала проверяют все новые данные и наличие записи. Только потом меняют объект. Если не найден ID или неверное количество, каталог остаётся прежним.

### Продажа — отдельное бизнес-действие

Простое Update позволяет заменить значения, а продажа подчиняется правилам: quantity>0, остатка хватает, иначе отказ. Не распределяйте эти проверки между двумя разными меню. Вычислительная функция должна одинаково работать при вызове из консоли и из бота.

### Удаление и ссылки

Remove удаляет элемент из списка, но переменная, которая уже ссылалась на объект, по-прежнему может его хранить. Поэтому не оставляйте открытый экран с устаревшей карточкой после удаления. Не меняйте список во время прямого перебора без продуманного алгоритма.

## Частые ошибки

Не используйте индекс как ID. Не печатайте «Успех» без проверки результата. Не меняйте часть полей до завершения валидации.

## Разбор практических задач

Сначала запишите свой план и ожидаемый результат, затем сравните с разбором.

### Задача 1. Поиск по ID

#### Условие

Верните товар с нужным ID либо None.

#### Как рассуждать и алгоритм

Последовательно проверьте записи. Вывод не входит в поиск.

#### Решение

```python
def find_by_id(products, target_id):
    for product in products:
        if product.id == target_id:
            return product
    return None
```

#### Проверка

На модели из теории ID 30 находится независимо от индекса; неизвестный ID и пустой каталог дают None.

### Задача 2. Удаление с результатом

#### Условие

Удалите найденную запись и верните bool.

#### Как рассуждать и алгоритм

Сначала используйте find_by_id из задачи 1, затем измените коллекцию.

#### Решение

```python
def delete_by_id(products, target_id):
    product = find_by_id(products, target_id)
    if product is None:
        return False
    products.remove(product)
    return True
```

#### Проверка

Первое удаление существующего ID даёт True, второе — False. Другие записи не меняются.

### Задача 3. Продажа

#### Условие

Уменьшите остаток только для допустимой операции.

#### Как рассуждать и алгоритм

Проверьте количество, наличие товара и остаток до присваивания.

#### Решение

```python
def sell(products, target_id, quantity):
    if quantity <= 0:
        return False
    product = find_by_id(products, target_id)
    if product is None or quantity > product.stock:
        return False
    product.stock -= quantity
    return True
```

#### Проверка

Из 5 продать 2 → остаток 3. Количество 0, -1, 6 при начальном 5 или неизвестный ID дают False без изменения.

## Самостоятельная практика

Реализуйте CRUD каталога услуг. Добавление получает данные без ID и выдаёт новый ID; изменение сохраняет прежний. Проверьте сценарий «добавить три → удалить вторую → добавить ещё одну»: ID не должны повториться.
