# Следующие темы курса

<p class="reading-time">Короткий обзор дальнейшего маршрута</p>

Большой консольный проект закрепляет базу Python. Дальше программа курса постепенно добавляет новые способы хранить данные, создавать интерфейсы и связывать разные приложения.

## Завершение Python-модуля

Следующие темы расширяют консольные проекты:

- словари, множества, кортежи, регулярные выражения, CSV и JSON;
- классы, наследование, абстракция и полиморфизм;
- PostgreSQL и базовые SQL-запросы;
- работа с сетью и внешними API;
- Telegram-боты на Python;
- выпускной проект модуля.

## C# и desktop-приложения

На следующем этапе появятся C#, WPF, графические интерфейсы, архитектура MVVM, MSSQL и Entity Framework. Консольное меню превратится в полноценное оконное приложение.

## Frontend-разработка

HTML и CSS отвечают за структуру и оформление сайтов, JavaScript — за интерактивность, React — за компонентные веб-приложения. Проекты можно будет публиковать в интернете.

## Java и backend

Java, Spring Boot, PostgreSQL и Docker позволят создавать серверную часть, REST API и общую систему для сайта, desktop-приложения и Telegram-бота.
