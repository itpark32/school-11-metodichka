# 14. Консольный UI

<p class="reading-time">Чтение: 5 минут</p>

UI — часть программы, через которую пользователь видит состояние и выполняет действия. Даже консольному интерфейсу нужны понятная навигация, проверка ввода и единый стиль сообщений.

!!! abstract "Фокус"
    - **Нужно знать:** меню, безопасный ввод, возврат и завершение программы.
    - **Часто в работе:** отдельные помощники ввода, роли и понятные сообщения.
    - **Достаточно узнавать:** оформление больших текстовых таблиц в консоли.

## Безопасный ввод

```python
def input_int(message, min_value, max_value):
    while True:
        try:
            value = int(input(message))
        except ValueError:
            print("Введите целое число")
            continue

        if min_value <= value <= max_value:
            return value
        print(f"Введите число от {min_value} до {max_value}")
```

Ввод проверяется в одном месте и возвращает уже корректное значение. По этому же принципу создаются `input_float()`, `input_str()` и `input_date()`.

## Вложенные меню

```text
Главное меню
├── Покупатель
│   ├── найти
│   ├── сортировать
│   └── купить
└── Администратор
    ├── добавить / изменить / удалить
    └── загрузить / сохранить
```

Каждое подменю получает свой цикл. Пункт `0` меняет его флаг и возвращает пользователя на уровень выше. После команды полезна пауза, чтобы результат не исчез под следующим меню.

## Отделяйте UI от правил

Меню спрашивает ID и показывает сообщение. Функция `buy_product()` решает, можно ли уменьшить остаток. Если смешать эти обязанности, ту же логику будет трудно перенести в Telegram-бот или графическое приложение.
