## Теория

Условие отвечает на вопрос с двумя ответами: да или нет. Например, `quantity > 0` проверяет, можно ли принять заказ. Сравнения `==`, `!=`, `<`, `<=`, `>`, `>=` возвращают `bool`.

### Один выбор или несколько проверок

```python
amount = 6000
if amount >= 5000:
    discount_percent = 10
elif amount >= 3000:
    discount_percent = 5
else:
    discount_percent = 0
print(discount_percent)
```

Цепочка выбирает первую подходящую ветку. Если написать несколько независимых `if`, могут выполниться несколько действий. Это полезно для независимых предупреждений, но опасно для взаимоисключающих тарифов.

### Соединяем правила

`and` требует выполнения обоих условий; `or` — хотя бы одного; `not` меняет ответ на противоположный. Для диапазона удобно `0 < quantity <= stock`.

Сначала формулируйте правило словами, затем записывайте выражение. «Доставка бесплатна при заказе от 5000 рублей или самовывозе» превращается в `amount >= 5000 or pickup`. Скобки помогают увидеть смысл сложного правила.

### Границы и некорректные значения

Для порога 5000 проверьте 4999, 5000 и 5001. Отдельно решите, что делать с отрицательной суммой. Правило «скидка от 5000» само по себе не описывает некорректный заказ.

## Частые ошибки

`=` и `==` делают разные вещи. Выражение `answer == "да" or "yes"` неверно: непустая строка сама считается истинной. Пишите `answer == "да" or answer == "yes"`.

## Разбор практических задач

Сначала составьте свой план решения. Затем сравните его с разбором и проверьте результат.

### Задача 1. Порог доставки

#### Условие

Доставка стоит 300 рублей и становится бесплатной от 5000 рублей. Сумма неотрицательная.

#### Как рассуждать и алгоритм

Сравните сумму с порогом, включая границу. Выберите ровно одну цену доставки.

#### Решение

```python
amount = 5000
if amount >= 5000:
    delivery = 0
else:
    delivery = 300
print(delivery)
```

#### Проверка

4999 → 300; 5000 → 0; 5001 → 0.

### Задача 2. Допуск к заказу

#### Условие

Заказ допустим, когда количество положительное и не превышает остаток.

#### Как рассуждать и алгоритм

Обе проверки обязательны. Нулевое количество не является заказом.

#### Решение

```python
quantity = 4
stock = 3
if 0 < quantity <= stock:
    print("Можно оформить")
else:
    print("Проверьте количество")
```

#### Проверка

При остатке 3: количество -1, 0 и 4 отклоняются; 1 и 3 принимаются.

### Задача 3. Приоритет скидок

#### Условие

От 10000 рублей скидка 10%, иначе постоянному клиенту 5%, остальным 0%. Скидки не складываются.

#### Как рассуждать и алгоритм

Сначала проверьте старшее правило по сумме. Только если оно не подошло, учитывайте статус клиента.

#### Решение

```python
amount = 12000
regular_customer = True
if amount >= 10000:
    percent = 10
elif regular_customer:
    percent = 5
else:
    percent = 0
print(amount * (100 - percent) // 100)
```

#### Проверка

12000 и постоянный → 10800; 2000 и постоянный → 1900; 2000 и новый → 2000. Здесь суммы подобраны без дробных рублей.
