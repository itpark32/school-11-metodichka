# 2. Условия и обработка ошибок

<p class="reading-time">Чтение: 7 минут</p>

Условия выбирают действие, а обработка ошибок не дает программе завершиться из-за неверного ввода.

!!! abstract "Фокус"
    - **Нужно знать:** `if`, `elif`, `else`, сравнения, `and`, `or`, `not`, `try`, `except`.
    - **Часто в работе:** проверка диапазона, ранний `return`, повторный ввод после ошибки.
    - **Достаточно узнавать:** несколько веток `except` и собственные типы исключений.

## Условие

```python
age = int(input("Возраст: "))

if age < 0:
    print("Возраст не может быть отрицательным")
elif age < 13:
    print("Нужен взрослый сопровождающий")
else:
    print("Можно продолжать")
```

Python проверяет ветви сверху вниз и выполняет первую истинную. Оператор `=` записывает значение, а `==` сравнивает два значения.

## Сложные условия

```python
price = 2400
amount = 2

if price > 0 and amount > 0:
    print("Сумма:", price * amount)
```

- `and` требует истинности обеих частей;
- `or` требует хотя бы одну истинную часть;
- `not` меняет логическое значение на противоположное.

Сложное условие легче читать, если каждая часть отвечает на один понятный вопрос.

## Ошибка преобразования

```python
try:
    answer = int(input("Введите число от 1 до 5: "))
except ValueError:
    print("Нужно ввести целое число")
else:
    if 1 <= answer <= 5:
        print("Вы выбрали:", answer)
    else:
        print("Число вне диапазона")
```

`int()` выбрасывает `ValueError`, если строку нельзя превратить в целое число. Перехватывайте ожидаемую конкретную ошибку, а не пишите пустой `except:` вокруг всей программы.

!!! warning "Ловушка: ошибка и неверное значение — не одно и то же"
    Строка `"кот"` вызывает ошибку преобразования, а число `99` успешно превращается в `int`, но не проходит проверку диапазона.
