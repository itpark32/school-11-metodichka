## Теория

Коллекция хранит несколько значений. Тип выбирают по тому, что программа будет с ними делать.

| Тип | Для чего подходит | Пример |
|---|---|---|
| `list` | Порядок, повторы, изменение | Заказы за день |
| `dict` | Поиск значения по ключу | Остаток по артикулу |
| `set` | Уникальность и проверка вхождения | Города доставки |
| `tuple` | Неизменяемый набор позиций | Координата склада |

### Список и индекс

Индексы начинаются с нуля. У трёх элементов индексы 0, 1, 2. `append` добавляет элемент, `pop` удаляет по индексу, `remove` — первое совпадение по значению. Перед поиском минимума или обращением к первому элементу проверьте, что список не пуст.

### Словарь и множество

```python
stock = {"A-1": 4, "B-2": 0}
print(stock.get("C-3", 0))
stock["A-1"] += 2
cities = {"Брянск", "Орёл", "Брянск"}
print(len(cities))
```

`get` позволяет договориться о результате для неизвестного ключа. Не всегда ноль — правильный ответ: иногда отсутствие товара нужно отличать от нулевого остатка. Множество убирает повторы, но не предоставляет индексы и не гарантирует нужный порядок вывода. Для отчёта используйте `sorted`.

### Три разных действия

Поиск отвечает «где нужный товар?», фильтрация — «какие товары подходят?», сортировка — «в каком порядке показать?». Линейный поиск последовательно проверяет элементы. `sorted(items)` создаёт новый список, `items.sort()` меняет существующий и возвращает `None`. Для словарей ключ сортировки задают функцией: `key=lambda item: item["price"]`.

## Частые ошибки

Не удаляйте элементы из списка во время его прямого перебора: можно пропустить следующий элемент. Не пишите `items = items.sort()`. Копия `b = a` не создаёт новый список.

### Задача 1. Товары с низким остатком

#### Условие

Покажите артикулы, у которых осталось меньше 3 единиц.

#### Как рассуждать и алгоритм

Переберите пары ключ–значение через `items()`. Отберите записи по условию.

#### Решение

```python
stock = {"A": 5, "B": 2, "C": 0}
for sku, quantity in stock.items():
    if quantity < 3:
        print(sku)
```

#### Проверка

Будут выведены B и C. Остаток 3 в отчёт не попадает.

### Задача 2. Города без повторов

#### Условие

Получите отсортированный список городов доставки.

#### Как рассуждать и алгоритм

Множество убирает дубли, сортировка делает порядок предсказуемым.

#### Решение

```python
cities = ["Тула", "Брянск", "Тула"]
print(sorted(set(cities)))
```

#### Проверка

Результат: `["Брянск", "Тула"]` в стандартном представлении Python с кавычками. Пустой список даёт пустой результат.

### Задача 3. Продажи по менеджерам

#### Условие

Для каждой пары «менеджер, сумма» накопите общую выручку.

#### Как рассуждать и алгоритм

Словарь хранит текущую сумму по имени. Для первого платежа используйте начальный ноль.

#### Решение

```python
sales = [("Анна", 1000), ("Борис", 700), ("Анна", 500)]
totals = {}
for manager, amount in sales:
    totals[manager] = totals.get(manager, 0) + amount
for manager in sorted(totals):
    print(manager, totals[manager])
```

#### Проверка

Анна → 1500, Борис → 700. Две одинаковые суммы одного менеджера должны учитываться обе.
