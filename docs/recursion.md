# 8. Рекурсия

<p class="reading-time">Чтение: 7 минут</p>

Рекурсивная функция вызывает сама себя. Каждый новый вызов решает более маленькую версию той же задачи.

!!! abstract "Фокус"
    - **Нужно знать:** условие остановки, рекурсивный шаг и `return`.
    - **Часто в работе:** уметь проследить спуск и возврат вызовов.
    - **Достаточно узнавать:** ограничение глубины рекурсии и стек вызовов.

## Две обязательные части

```python
def countdown(number):
    if number == 0:          # условие остановки
        print("Старт!")
        return

    print(number)
    countdown(number - 1)    # шаг к остановке
```

Без условия остановки вызовы продолжатся, пока Python не завершит программу с `RecursionError`. Если аргумент не приближается к остановке, условие никогда не наступит.

## Спуск и возврат

```python
def show(number):
    print("вход", number)
    if number > 1:
        show(number - 1)
    print("выход", number)


show(3)
```

Сначала появятся `вход 3`, `вход 2`, `вход 1`. Затем функции завершатся в обратном порядке: `выход 1`, `выход 2`, `выход 3`.

## Рекурсия или цикл

Счет от 1 до 100 проще написать циклом. Рекурсия становится естественной, когда задача содержит такие же вложенные подзадачи. Например, при обходе дерева папок или вычислении значения по рекурсивному определению.

!!! warning "Ловушка: забытый return"
    Если рекурсивная функция должна вычислить результат, обычно нужно вернуть и результат вложенного вызова: `return number * factorial(number - 1)`.
