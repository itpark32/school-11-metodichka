## Теория

Пользователь может ввести название с лишними пробелами и другим регистром. Прежде чем сравнивать данные, приведите их к согласованному виду. При этом исходное написание имени или адреса иногда нужно сохранить для показа.

### Методы создают новый текст

```python
raw = "  Брянск  "
city = raw.strip()
search_key = city.casefold()
print(city, search_key)
```

`strip` убирает пробельные символы по краям, `lower` переводит в нижний регистр, `casefold` удобен для сравнения без учёта регистра. `replace` заменяет фрагменты, `in` проверяет вхождение. `find` возвращает индекс или -1, если фрагмента нет.

Строка неизменяема: `name[0] = "А"` не работает. Сохраните результат метода в переменную, если он нужен дальше.

### Части строки и форматирование

`text[start:stop:step]` берёт срез, не включая `stop`. `text[:3]` — первые три символа, `text[-4:]` — последние четыре, `text[::-1]` — обратный порядок. Перед `text[0]` проверьте непустую строку; срез короткой строки допустим.

`split()` без аргумента разбивает по группам пробельных символов. `";".join(parts)` соединяет строки. Для настоящего CSV используйте модуль `csv`: разделитель может встретиться внутри значения.

Регулярные выражения описывают форму строки. Например, `re.fullmatch(r"[A-Z]{2}-[0-9]{4}", code)` проверяет артикул вида AB-1234. Они не заменяют проверку бизнес-смысла: правильный формат ещё не означает, что товар существует.

## Частые ошибки

Метод `strip` не удаляет все пробелы внутри строки. Не используйте `find` как логическое значение: найденный индекс 0 считается ложным, а -1 — истинным. Для наличия фрагмента пишите `in`.

## Разбор практических задач

Сначала составьте свой план решения. Затем сравните его с разбором и проверьте результат.

### Задача 1. Нормализация названия

#### Условие

Удалите пробелы по краям и сравните город без учёта регистра.

#### Как рассуждать и алгоритм

Храните читаемое имя отдельно от ключа сравнения.

#### Решение

```python
raw = "  БрЯнСк "
city = raw.strip()
print(city.casefold() == "брянск")
```

#### Проверка

Результат True. Пустой ввод после strip требует отдельного отказа при оформлении заказа.

### Задача 2. Краткий номер заказа

#### Условие

Для отображения возьмите последние четыре символа номера.

#### Как рассуждать и алгоритм

Срез с отрицательной границей работает и для короткой строки.

#### Решение

```python
order_id = "ORDER-2026-0123"
print(order_id[-4:])
```

#### Проверка

Получится 0123. Для "AB" получится AB. Это оформление текста, а не защита секретных данных.

### Задача 3. Список услуг из ввода

#### Условие

Из строки с услугами через запятую получите список без пустых элементов и внешних пробелов.

#### Как рассуждать и алгоритм

Разбейте ввод, очистите каждый фрагмент и добавляйте только непустые названия.

#### Решение

```python
raw = " доставка, упаковка, , самовывоз "
services = []
for part in raw.split(","):
    name = part.strip()
    if name:
        services.append(name)
print(" | ".join(services))
```

#### Проверка

Получится `доставка | упаковка | самовывоз`. Строка ", ," даёт пустой результат.
