# 1. Данные и условия

<p class="reading-time">Чтение: 4 минуты</p>

Программа получает данные, сохраняет их, выполняет вычисления и выбирает действие. На этом построены и калькулятор здоровья, и проверка символа, и меню большого проекта.

## Ввод, типы и арифметика

```python
name = input("Как тебя зовут? ")
age = int(input("Сколько тебе лет? "))
height = float(input("Рост в метрах: "))

bmi_hint = age / (height ** 2)
print(f"{name}, учебный показатель: {bmi_hint:.1f}")
```

`input()` всегда возвращает `str`. Для вычислений строку преобразуют в `int` или `float`. Операторы `//` и `%` дают целую часть и остаток от деления — так удобно разбирать число на цифры.

## Условие

```python
symbol = input("Введите один символ: ")

if len(symbol) != 1:
    print("Нужен ровно один символ")
elif symbol.isdigit():
    print("Это цифра")
elif symbol.isalpha():
    print("Это буква")
else:
    print("Это другой знак")
```

Python проверяет ветви сверху вниз и выполняет первую истинную. `and`, `or`, `not` соединяют условия. Не путайте `=` — сохранить значение — и `==` — сравнить значения.
