## Теория

Программа получает исходные данные, выполняет действия и выдаёт результат. Для магазина исходные данные — цена и количество товара; результат — сумма заказа. До кода полезно записать формулу и посчитать один пример вручную.

### Значение и тип

```python
product = input("Товар: ")
price = int(input("Цена в рублях: "))
quantity = int(input("Количество: "))
total = price * quantity
print(f"{product}: {total} руб.")
```

`input()` всегда возвращает строку. Даже введённое `12` сначала является текстом. `int` преобразует запись целого числа; `float` — числа с дробной частью. Переменная хранит значение, а имя помогает понять его смысл: `quantity` понятнее, чем `x`.

`str` — текст, `int` — целое число, `float` — приближённое дробное число, `bool` — `True` или `False`. Выражение `"12" + "3"` даёт `"123"`, а `12 + 3` даёт `15`.

### Операции и единицы

`+`, `-`, `*`, `/` выполняют арифметические действия, `**` возводит в степень. Деление `/` возвращает дробный результат; `//` даёт целую часть частного с округлением вниз, `%` — остаток. Например, `17 // 5 == 3`, `17 % 5 == 2`.

Скобки делают порядок действий явным. Имена `price_kopecks`, `duration_minutes` показывают единицы измерения. Для денежных расчётов здесь используем целые копейки, а в простых примерах без дробных цен — целые рубли. `float` может хранить `0.1` неточно, поэтому для денег бездумно его применять нельзя.

В этой главе считаем ввод корректным. Проверять ограничения научимся в [условиях](conditions-errors.md), обрабатывать ввод `abc` — в [исключениях](files-errors.md).

## Частые ошибки

Не складывайте строковые числа. Не смешивайте рубли и копейки. Присваивание `=` сохраняет значение справа под именем слева; оно не является математическим равенством.

## Разбор практических задач

Сначала составьте свой план решения. Затем сравните его с разбором и проверьте результат.

### Задача 1. Стоимость партии

#### Условие

Тетрадь стоит 75 рублей. Найдите стоимость 18 тетрадей.

#### Как рассуждать и алгоритм

Определите цену одной единицы и количество. Умножьте их: 75 × 18.

#### Решение

```python
price = 75
quantity = 18
print(price * quantity)
```

#### Проверка

Результат: `1350`. Для количества `0` получится `0`, для `1` — `75`.

### Задача 2. Коробки для доставки

#### Условие

В коробку входит 6 товаров. Нужно упаковать 25 товаров. Найдите число полных коробок и остаток.

#### Как рассуждать и алгоритм

Целочисленное деление считает полные коробки, остаток показывает неупакованные товары.

#### Решение

```python
quantity = 25
capacity = 6
print("Полных:", quantity // capacity)
print("Остаток:", quantity % capacity)
```

#### Проверка

Получится `4` и `1`. Для 24 товаров: `4` и `0`; для 0: `0` и `0`.

### Задача 3. Счёт в копейках

#### Условие

Цена услуги 149 рублей 90 копеек. Клиент заказал 3 услуги. Выведите итог в рублях и копейках.

#### Как рассуждать и алгоритм

Сначала переведите цену в копейки. Умножайте целые числа. Для вывода разделите итог на рубли и остаток копеек.

#### Решение

```python
price_kopecks = 149 * 100 + 90
total = price_kopecks * 3
print(f"{total // 100} руб. {total % 100:02d} коп.")
```

#### Проверка

Результат: `449 руб. 70 коп.`. Цена 10005 копеек за одну услугу должна выводиться как `100 руб. 05 коп.`.
