# 1. Данные и арифметика

<p class="reading-time">Чтение: 4 минуты</p>

Программа получает данные, сохраняет их, выполняет вычисления и показывает результат. На этом построены и первый калькулятор, и большое приложение с каталогом.

!!! abstract "Фокус"
    - **Нужно знать:** `print`, `input`, переменная, `int`, `float`, `str`, основные операции.
    - **Часто в работе:** f-строки, понятные имена, `//` и `%` для работы с цифрами числа.
    - **Достаточно узнавать:** сложные правила округления дробных чисел.

## Ввод, типы и арифметика

```python
name = input("Как тебя зовут? ")
age = int(input("Сколько тебе лет? "))
height = float(input("Рост в метрах: "))

bmi_hint = age / (height ** 2)
print(f"{name}, учебный показатель: {bmi_hint:.1f}")
```

`input()` всегда возвращает `str`. Для вычислений строку преобразуют в `int` или `float`. Операторы `//` и `%` дают целую часть и остаток от деления — так удобно разбирать число на цифры.

## Операции с числами

| Оператор | Действие | Результат |
|---|---|---|
| `10 + 3` | сложение | `13` |
| `10 / 3` | обычное деление | `3.333...` |
| `10 // 3` | целая часть | `3` |
| `10 % 3` | остаток | `1` |
| `2 ** 4` | степень | `16` |

Скобки явно показывают порядок вычислений. Не превращайте длинную формулу в одну непонятную строку — сохраните промежуточные результаты в переменные.
