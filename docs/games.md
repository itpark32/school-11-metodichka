# 5. Двумерные списки и игры

<p class="reading-time">Чтение: 5 минут</p>

Двумерный список — список строк, каждая из которых тоже является списком. Такая структура подходит для таблиц и игровых полей.

!!! abstract "Фокус"
    - **Нужно знать:** строка, столбец, два индекса и обход поля вложенными циклами.
    - **Часто в работе:** константы состояний клетки, проверка координат и правила хода.
    - **Достаточно узнавать:** случайная расстановка объектов без повторений.

## Создание поля

```python
size = 5
EMPTY = "."
field = []

for row in range(size):
    field.append([])
    for column in range(size):
        field[row].append(EMPTY)
```

Клетка задаётся двумя индексами: `field[row][column]`. Если игрок вводит координаты от 1, перед обращением к списку нужно вычесть единицу.

## Состояние клетки

```python
ALIVE_SHIP = "K"
DEAD_SHIP = "X"
MISS = "O"

if field[row][column] == ALIVE_SHIP:
    field[row][column] = DEAD_SHIP
elif field[row][column] == EMPTY:
    field[row][column] = MISS
```

Одна клетка хранит состояние. Вся игра хранит ещё и текущего игрока, число живых кораблей и признак продолжения. После каждого действия программа меняет состояние и снова показывает поле.
