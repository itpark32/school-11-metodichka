# Двумерные списки и таблицы

<p class="reading-time">Примерное время · Чтение: 4–7 мин · Практика: 35–55 мин</p>

!!! abstract "Фокус"
    - **Нужно знать:** строка, столбец, вложенный список и вложенный цикл.
    - **Нужно уметь:** хранить сетку мест или таблицу показателей.

## Теория

Двумерный список — список строк, каждая из которых тоже является списком. У клетки два индекса: `table[row][column]`. В школьных играх это поле, в рабочем приложении — места в зале, расписание или продажи филиалов по дням.

### Создаём независимые строки

```python
seats = []
for row in range(3):
    seats.append([0] * 4)
seats[1][2] = 1
```

В зале три ряда по четыре места. Ноль означает свободное место, единица — занятое. Запись `[[0] * 4] * 3` повторяет ссылки на одну и ту же строку. Изменив одну клетку, вы неожиданно измените несколько рядов. Каждую строку создавайте отдельно.

### Перебираем таблицу

```python
for row in seats:
    print(*row)
```

Когда нужны координаты, используйте два цикла с индексами. Внешний выбирает строку, внутренний — столбец. До обращения к клетке проверьте `0 <= row < len(seats)` и границу столбца для выбранной строки.

Не каждая таблица прямоугольная. Если программа ожидает одинаковую длину строк, это нужно проверить при загрузке данных. Для бронирования также важно проверить, что место свободно, прежде чем изменить значение.

## Частые ошибки

Отрицательный индекс в Python допустим и обращается с конца, поэтому проверка только верхней границы недостаточна. Не путайте строки со столбцами.

## Разбор практических задач

Сначала составьте свой план решения. Затем сравните его с разбором и проверьте результат.

### Задача 1. Свободные места

#### Условие

Сосчитайте нули в заданном зале.

#### Как рассуждать и алгоритм

Пройдите по всем строкам, затем по клеткам. Увеличивайте счётчик только для свободной клетки.

#### Решение

```python
seats = [[0, 1, 0], [1, 1, 0]]
free = 0
for row in seats:
    for seat in row:
        if seat == 0:
            free += 1
print(free)
```

#### Проверка

Получится 3. Полностью занятый зал даёт 0; пустой список — 0.

### Задача 2. Продажи филиалов

#### Условие

Каждая строка хранит продажи одного филиала за три дня. Выведите итог по филиалам.

#### Как рассуждать и алгоритм

Суммируйте строки независимо. Номер для человека начинайте с единицы.

#### Решение

```python
sales = [[100, 200, 50], [300, 0, 100]]
for branch, row in enumerate(sales, start=1):
    print(branch, sum(row))
```

#### Проверка

Филиал 1 → 350, филиал 2 → 400. Нулевой день остаётся частью отчёта.

### Задача 3. Бронирование

#### Условие

Забронируйте место по индексам. Отклоните неверную координату и повторную бронь.

#### Как рассуждать и алгоритм

Сначала проверьте границы. Затем занятость. Меняйте таблицу только после обеих проверок.

#### Решение

```python
seats = [[0, 0], [1, 0]]
row, column = 1, 0
if not (0 <= row < len(seats)):
    print("Нет такого ряда")
elif not (0 <= column < len(seats[row])):
    print("Нет такого места")
elif seats[row][column] == 1:
    print("Уже занято")
else:
    seats[row][column] = 1
    print("Забронировано")
```

#### Проверка

(1, 0) → уже занято; (0, 1) → забронировано; (-1, 0) → нет такого ряда. Для пользователя номера 1..N сначала переводите в индексы 0..N-1.

## Самостоятельная практика

Создайте сетку занятости переговорных: 3 комнаты × 8 часовых слотов. Реализуйте бронь одного слота и подсчёт свободных слотов каждой комнаты. Повторная бронь не должна менять данные.
