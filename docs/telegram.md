# Telegram-бот: команды, обработчики и кнопки

## Теория

Бот получает события от Telegram и вызывает подходящие функции. Команда, текст и нажатие inline-кнопки — разные события. В курсе используется пакет pyTelegramBotAPI, импортируемый как `telebot`.

### Подготовка и запуск

Создайте учебного бота через BotFather. Установите `pyTelegramBotAPI`, задайте TELEGRAM_BOT_TOKEN в окружении. Следующий пример — отдельный main.py:

```python
import os
import telebot

bot = telebot.TeleBot(os.environ["TELEGRAM_BOT_TOKEN"], threaded=False)

@bot.message_handler(commands=["start"])
def start(message):
    bot.send_message(message.chat.id, "Напишите название услуги")

@bot.message_handler(content_types=["text"])
def answer(message):
    bot.send_message(message.chat.id, f"Вы выбрали: {message.text}")

if __name__ == "__main__":
    bot.infinity_polling()
```

Декораторы регистрируют обработчики. Порядок важен: специализированные обработчики ставьте перед общим обработчиком текста. В этом учебном примере `threaded=False` упрощает последовательную обработку; медленная операция будет задерживать ответы всем пользователям. Для большого проекта нужны отдельное управление состояниями и продуманная работа с конкурентностью.

### Пользователь и чат

`message.chat.id` определяет чат для ответа. `message.from_user.id` определяет пользователя. В личной переписке различие легко не заметить, но в группе в одном чате пишут разные люди. Для личных данных используйте идентификатор владельца.

Reply-клавиатура отправляет обычное сообщение. Inline-клавиатура отправляет callback_data. На callback нужно ответить через answer_callback_query, чтобы завершить индикатор ожидания. Данные кнопки следует проверять так же, как любой внешний ввод.

Токен — секрет. Если он попал в репозиторий, отзовите его через BotFather. Переменная окружения предотвращает хранение секрета в исходниках, но не делает безопасным его вывод в логи.

## Частые ошибки

Общий обработчик текста может перехватить команду, если зарегистрирован раньше. Не храните один глобальный заказ на всех пользователей. Не путайте callback_data с видимой надписью кнопки.

## Разбор практических задач

### Задача 1. Справка

#### Условие

Добавьте команду /help в основной пример.

#### Как рассуждать и алгоритм

Обработчик разместите до общего answer и до запуска polling.

#### Решение

```python
# Добавьте к боту из теории до answer
@bot.message_handler(commands=["help"])
def help_command(message):
    bot.send_message(message.chat.id, "Отправьте услугу. /start — начать заново")
```

#### Проверка

/help даёт справку, обычный текст продолжает обрабатываться answer. Запускайте только один процесс polling для этого бота.

### Задача 2. Кнопка каталога

#### Условие

Добавьте /catalog с inline-кнопкой и отдельным обработчиком нажатия.

#### Как рассуждать и алгоритм

Создайте клавиатуру, задайте стабильную callback_data и ответьте на callback.

#### Решение

```python
# До общего текстового обработчика и polling
from telebot.types import InlineKeyboardMarkup, InlineKeyboardButton
@bot.message_handler(commands=["catalog"])
def catalog(message):
    keyboard = InlineKeyboardMarkup()
    keyboard.add(InlineKeyboardButton("Упаковка", callback_data="service:pack"))
    bot.send_message(message.chat.id, "Услуги", reply_markup=keyboard)

@bot.callback_query_handler(func=lambda call: call.data == "service:pack")
def choose_pack(call):
    bot.answer_callback_query(call.id, "Услуга выбрана")
```

#### Проверка

/catalog показывает кнопку. Нажатие завершает ожидание и показывает уведомление. Состояние заказа здесь пока не сохраняется.

### Задача 3. Расчёт отдельно от бота

#### Условие

Оформите текст расчёта стоимости услуги чистой функцией.

#### Как рассуждать и алгоритм

Функция должна принимать проверенные данные и возвращать текст. Обработчик позже передаст его send_message.

#### Решение

```python
def quote_text(price, quantity):
    if quantity <= 0:
        return "Укажите положительное количество"
    return f"К оплате: {price * quantity} руб."
print(quote_text(150, 3))
```

#### Проверка

Получится «К оплате: 450 руб.». Количество 0 даёт пояснение. Функцию можно проверить без Telegram.
