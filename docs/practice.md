# Мини-задачи для повторения

<p class="reading-time">Практика: от 10 до 40 минут на блок</p>

Решайте без копирования готового проекта. Сначала запишите входные данные, ожидаемый результат и несколько примеров проверки.

## База Python

- Запросите цену и количество, посчитайте сумму и примените скидку по условию.
- Принимайте целое число в заданном диапазоне, пока пользователь не введет корректное значение.
- Найдите сумму цифр числа с помощью `//` и `%`.

## Циклы и коллекции

- Выведите таблицу умножения размером 10×10 вложенными циклами.
- Найдите минимум, максимум и среднее списка без готовых функций.
- Удалите повторяющиеся имена, сохранив понятный результат.
- Посчитайте частоту букв в строке с помощью словаря.

## Игры

- Сделайте поле 5×5 и разместите пять сокровищ без повторений.
- Добавьте в «Угадай число» уровни сложности и лучший результат.
- Опишите текстовый квест как набор состояний и переходов, затем реализуйте три комнаты.

## Функции и файлы

- Разделите игру на ввод, изменение состояния, проверку завершения и вывод.
- Сохраните таблицу результатов в текстовый файл и восстановите ее после перезапуска.
- Обработайте отсутствующий файл и испорченную строку без аварийного завершения.

## CRUD-приложение

- Создайте модель `Game`: ID, название, жанр, цена, рейтинг и количество.
- Реализуйте добавление, поиск по ID, изменение и удаление до создания меню.
- Добавьте поиск по части названия и диапазону цены.
- Отсортируйте игры по рейтингу и цене через `key=lambda ...`.
- Создайте меню гостя и администратора с безопасным вводом.

## Финальная проверка

- [ ] Я могу объяснить каждую функцию своего проекта.
- [ ] Неверный ввод не завершает программу.
- [ ] Пустой список обрабатывается отдельно.
- [ ] ID объекта не зависит от его позиции.
- [ ] После сохранения и загрузки данные не меняются.
- [ ] Новую возможность можно добавить без переписывания всего проекта.
