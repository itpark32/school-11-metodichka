# Поиск, фильтры, ключи и сортировка объектов

<p class="reading-time">Примерное время · Чтение: 4–6 мин · Практика: 35–60 мин</p>

!!! abstract "Фокус"
    - **Нужно знать:** точный поиск, подстрока, диапазон, key, reverse и стабильный порядок.
    - **Нужно уметь:** получить выборку без изменения каталога и задать явный критерий сортировки.

## Теория

Поиск отвечает «какие записи подходят», сортировка — «в каком порядке показать». Сначала определите критерий: ID, часть названия, категория, диапазон цены. Для каталога из нескольких десятков записей простой перебор часто достаточно понятен.

### Нормализация текста

Очистите края через strip, для сравнения без регистра используйте casefold или lower. Исходное название сохраняйте для показа. Пустой запрос — особый случай: пустая строка содержится в любом названии. Заранее решите, означает ли он «все» или ошибку. В упражнениях пустой поиск отклоняется.

### Диапазон

Сравнение minimum<=price<=maximum включает обе границы. Проверьте minimum<=maximum до перебора. Пустая выборка при корректном диапазоне — нормальный результат, а не отсутствие самого каталога.

### Sort и sorted

Sort меняет существующий список и возвращает None. Sorted создаёт новый. Для разового показа обычно удобен sorted: он не переставляет записи основного каталога. При этом объекты в новом списке остаются теми же объектами, а не глубокими копиями.

```python
items = [{"id": 2, "price": 300}, {"id": 1, "price": 300}]
ordered = sorted(items, key=lambda item: (item["price"], item["id"]))
```

Ключ вычисляет сравниваемое значение. Кортеж задаёт второй критерий при равенстве первого. Reverse=True меняет общий порядок; если нужны разные направления по полям, задавайте ключ осознанно. При равных ключах Python сохраняет исходный относительный порядок — сортировка стабильна.

### Учебный ручной алгоритм

В ручной сортировке сравнивали соседние записи и меняли местами. Сравнивать нужно выбранное поле, а не весь объект без договора сравнения. Двойной цикл имеет квадратичный рост работы; полезен для понимания, но встроенная сортировка обычно лучше для прикладной задачи.

### Сначала результат, затем вывод

Функция поиска возвращает список, а UI показывает таблицу или сообщение «Ничего не найдено». Тогда один фильтр можно использовать в консоли, экспорте и Telegram.

## Частые ошибки

Не присваивайте результат sort обратно списку. Не путайте отсутствие совпадений с ошибкой загрузки. ID не меняется вслед за сортировкой.

## Разбор практических задач

Сначала запишите свой план и ожидаемый результат, затем сравните с разбором.

### Задача 1. Часть названия

#### Условие

Найдите услуги по тексту без учёта регистра.

#### Как рассуждать и алгоритм

Нормализуйте запрос один раз, затем переберите записи.

#### Решение

```python
def find_by_name(items, query):
    query = query.strip().casefold()
    if not query:
        raise ValueError("Пустой запрос")
    return [item for item in items if query in item["name"].casefold()]
print(find_by_name([{"name": "Упаковка"}], " УПАК "))
```

#### Проверка

Услуга найдена. Пустая строка отклоняется; «ремонт» даёт пустой список.

### Задача 2. Цена в границах

#### Условие

Верните услуги с ценой от minimum до maximum.

#### Как рассуждать и алгоритм

Отклоните перевёрнутый диапазон до фильтрации.

#### Решение

```python
def filter_price(items, minimum, maximum):
    if minimum > maximum:
        raise ValueError("Неверный диапазон")
    return [item for item in items if minimum <= item["price"] <= maximum]
```

#### Проверка

Для цен 100, 200, 300 диапазон 100..200 включает первые две. 201..299 даёт пустой список.

### Задача 3. Порядок отчёта

#### Условие

Сортируйте по возрастанию цены, при равенстве — по ID.

#### Как рассуждать и алгоритм

Ключ-кортеж делает дополнительное правило явным.

#### Решение

```python
items = [{"id": 2, "price": 100}, {"id": 1, "price": 100}, {"id": 3, "price": 50}]
ordered = sorted(items, key=lambda item: (item["price"], item["id"]))
print([item["id"] for item in ordered])
```

#### Проверка

Порядок 3, 1, 2. Основной items остаётся в прежнем порядке.
