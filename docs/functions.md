## Теория

Функция даёт имя законченному действию. Вместо повторяющегося расчёта доставки появляется `delivery_cost(amount)`. Такой расчёт можно вызывать из консоли, бота и теста.

### Договор функции

```python
def delivery_cost(amount):
    if amount < 0:
        raise ValueError("Сумма не может быть отрицательной")
    if amount >= 5000:
        return 0
    return 300
```

Контракт описывает вход, выход и недопустимые данные. Параметр `amount` получает аргумент конкретного вызова. `return` передаёт результат вызывающему коду и завершает вызов. `print` показывает текст; без явного `return` функция возвращает `None`.

Переменные внутри функции локальные. Передавайте зависимости параметрами: скрытая зависимость от глобального `amount` мешает повторному использованию. Не задавайте изменяемый список значением по умолчанию: он будет общим для вызовов. Используйте `None` и создавайте список внутри.

### От сценария к функциям

Меню получает команду, функция вычисляет результат, отдельная функция показывает его. «Посчитать», «сохранить» и «напечатать» — разные действия. Не нужно разбивать каждую строку в отдельную функцию; выделяйте законченные понятные шаги.

### Короткие выражения и рекурсия

`lambda item: item["price"]` подходит для ключа сортировки. `sum(value for value in values if value > 0)` обрабатывает элементы по одному без создания промежуточного списка. Сложный сценарий лучше читается как обычный цикл.

Рекурсия — вызов функцией самой себя. Нужны базовый случай и приближение к нему. Для обычного списка заказов цикл проще; рекурсия полезна для вложенных категорий. Бесконечные вложенные вызовы заканчиваются `RecursionError`.

## Частые ошибки

Не подменяйте `return` печатью. Не называйте переменные `sum`, `list`, `input`: это перекроет встроенные функции. Изменение переданного списка может быть видно вызывающему коду — это должно быть частью договора.

### Задача 1. Стоимость услуги

#### Условие

Напишите функцию стоимости партии по цене и количеству.

#### Как рассуждать и алгоритм

Функция получает два числа и возвращает произведение. Печать оставьте вызывающему коду.

#### Решение

```python
def batch_cost(price, quantity):
    return price * quantity
print(batch_cost(150, 4))
```

#### Проверка

Результат 600. Цена 0 или количество 0 дают 0; проверку отрицательных значений можно добавить к контракту.

### Задача 2. Средний чек

#### Условие

Верните среднюю сумму заказов, а для пустого списка — None.

#### Как рассуждать и алгоритм

Отсутствие данных отличается от среднего ноль. Проверьте пустоту до деления.

#### Решение

```python
def average_order(amounts):
    if not amounts:
        return None
    return sum(amounts) / len(amounts)
print(average_order([100, 200]))
print(average_order([]))
```

#### Проверка

Результаты 150.0 и None. Для [0] результат 0.0, а не None.

### Задача 3. Вложенные категории

#### Условие

Категория содержит числа или вложенные списки. Посчитайте общее число товаров: [2, [3, 1], 4].

#### Как рассуждать и алгоритм

Число — базовый случай. Для списка сложите результаты рекурсивного обхода его элементов. Контракт допускает только неотрицательные целые и списки.

#### Решение

```python
def count_products(node):
    if isinstance(node, int):
        return node
    return sum(count_products(child) for child in node)
print(count_products([2, [3, 1], 4]))
```

#### Проверка

Результат 10. Пустая категория [] даёт 0, [2, []] — 2. Глубоко вложенные данные требуют другого подхода.
