## Теория

API возвращает структуру для программ, например JSON. HTML описывает страницу для браузера. Парсинг извлекает данные из этой страницы по её структуре. Если нужный API существует и подходит задаче, изучите его договор; если данные доступны только на странице, разберите HTML.

### Что ищем в HTML

```html
<article class="service" data-id="7">
  <h2>Упаковка</h2>
  <span class="price">150</span>
</article>
```

Article — тег, class и data-id — атрибуты, h2/span — вложенные элементы. Селектор .service находит элементы класса service, .price — класса price. Класс не обязательно уникален, id по смыслу документа должен определять конкретный элемент.

### Разбор без интернета

Установите beautifulsoup4; импорт выполняется из bs4. Для первых задач используйте искусственный HTML: результат не зависит от изменения чужого сайта.

```python
from bs4 import BeautifulSoup
html = '<h2 class="name">  Упаковка </h2>'
soup = BeautifulSoup(html, "html.parser")
node = soup.select_one(".name")
print(node.get_text(strip=True) if node else "Нет названия")
```

Select_one возвращает один элемент либо None, select — список. Get_text извлекает текст; get("href") читает атрибут. У select с отсутствующим селектором получится пустой список, у select_one — None. Нельзя вызывать get_text у отсутствующего элемента.

### Сначала общий блок, затем поля

Если карточек несколько, переберите .service и ищите название/цену **внутри каждой карточки**. Отдельные списки всех названий и всех цен могут рассогласоваться при пропуске одного поля. Договоритесь, пропускать такую карточку или выдавать ошибку структуры.

### Загрузка страницы отдельно

Requests.get получает документ, raise_for_status проверяет HTTP-ошибку, response.text передаётся парсеру. Обязательно задайте timeout. Не выполняйте сетевой запрос в самой функции, проверяющей селектор: раздельные части легче тестировать.

### Ограничения

Структура страницы может измениться. JavaScript может добавлять данные уже в браузере, поэтому в исходном response.text их не будет. Не маскируйте изменение селектора под «товаров нет». Учитывайте правила сайта и частоту запросов; для курса достаточно локальных HTML и доступных учебных страниц.

## Частые ошибки

Не ищите все поля независимо по всей странице. Не вызывайте метод у None. Текст цены ещё нужно преобразовать и проверить. Парсер HTML не выполняет JavaScript.

## Разбор практических задач

Сначала запишите свой план и ожидаемый результат, затем сравните с разбором.

### Задача 1. Одна цена

#### Условие

Извлеките цену из учебного блока.

#### Как рассуждать и алгоритм

Найдите span.price и явно проверьте его наличие.

#### Решение

```python
from bs4 import BeautifulSoup
soup = BeautifulSoup('<span class="price">150</span>', "html.parser")
node = soup.select_one(".price")
if node is None:
    raise ValueError("Нет цены")
price = int(node.get_text(strip=True))
print(price)
```

#### Проверка

150. Селектор .cost не должен незаметно дать цену 0.

### Задача 2. Несколько карточек

#### Условие

Верните названия из повторяющихся блоков.

#### Как рассуждать и алгоритм

Переберите общий контейнер, затем проверьте поле каждой записи.

#### Решение

```python
from bs4 import BeautifulSoup

def service_names(html):
    soup = BeautifulSoup(html, "html.parser")
    result = []
    for card in soup.select(".service"):
        name = card.select_one("h2")
        if name is None:
            raise ValueError("Карточка без названия")
        result.append(name.get_text(strip=True))
    return result
```

#### Проверка

Две карточки дают два названия. Нет карточек → []; карточка без h2 → ValueError.

### Задача 3. Атрибут ссылки

#### Условие

Получите адрес ссылки из href.

#### Как рассуждать и алгоритм

Наличие элемента и наличие атрибута проверяются отдельно.

#### Решение

```python
from bs4 import BeautifulSoup
soup = BeautifulSoup('<a class="details" href="/services/7">Подробнее</a>', "html.parser")
link = soup.select_one("a.details")
href = None if link is None else link.get("href")
print(href)
```

#### Проверка

/services/7. Это относительный адрес; перед запросом его соединяют с базовым URL, а не считают полным.
