# Циклы, счётчики и накопление результата

<p class="reading-time">Примерное время · Чтение: 5–7 мин · Практика: 25–40 мин</p>

!!! abstract "Фокус"
    - **Нужно знать:** `while`, `for`, `range`, `break`, `continue`.
    - **Нужно уметь:** обработать серию операций и объяснить завершение цикла.

## Теория

Цикл нужен, когда одно действие выполняется для нескольких данных: посчитать выручку по дням, принять несколько платежей или повторять меню до выхода.

### Повторять, пока выполняется условие

```python
command = input("1 — отчёт, 0 — выход: ")
while command != "0":
    if command == "1":
        print("Отчёт готов")
    command = input("1 — отчёт, 0 — выход: ")
```

Внутри `while` меняются данные, от которых зависит условие. Иначе цикл не завершится. `break` немедленно завершает ближайший цикл. `continue` пропускает оставшуюся часть текущего повторения.

### Перебор известного набора

`for` проходит по элементам, а `range(1, 8)` выдаёт числа от 1 до 7. Правая граница не входит. `range(5)` начинается с нуля; `range(10, 0, -2)` идёт назад с шагом 2.

Сумма начинается с `0`, счётчик — с `0`. Минимум нельзя всегда начинать с нуля: если все продажи положительные, ноль ошибочно останется минимальным. Берите первый элемент непустой последовательности или отдельно обрабатывайте отсутствие данных.

### Трассировка

Запишите таблицу «значение → условие → сумма → счётчик». Для платежей 100, -5, 200 она позволяет увидеть, что отрицательная операция пропущена, сумма равна 300, счётчик равен 2. Пустой набор тоже требует проверки: у него нет среднего без отдельного соглашения.

## Частые ошибки

Не обнуляйте сумму внутри цикла. Проверяйте шаг и условие остановки. `break` во вложенных циклах завершает только ближайший цикл.

## Разбор практических задач

Сначала составьте свой план решения. Затем сравните его с разбором и проверьте результат.

### Задача 1. План на неделю

#### Условие

Каждый день магазин планирует получать 1200 рублей. Выведите план на 7 дней.

#### Как рассуждать и алгоритм

Повторите прибавление семь раз. Аккумулятор создайте до цикла.

#### Решение

```python
total = 0
for day in range(1, 8):
    total += 1200
print(total)
```

#### Проверка

Итог 8400. При нуле дней цикл не выполняется, итог остаётся нулевым.

### Задача 2. Только положительные платежи

#### Условие

В списке есть ошибочные отрицательные значения. Сосчитайте сумму и количество положительных платежей.

#### Как рассуждать и алгоритм

Пропускайте неположительные значения. Сумму и счётчик меняйте только для принятого платежа.

#### Решение

```python
payments = [100, -5, 0, 200]
total = 0
count = 0
for payment in payments:
    if payment <= 0:
        continue
    total += payment
    count += 1
print(total, count)
```

#### Проверка

Результат: `300 2`. Пустой список и список [-1, 0] дают `0 0`.

### Задача 3. Накопление бюджета

#### Условие

Начальная сумма 1000 рублей, каждую неделю откладываем 700. Сколько недель нужно до 4000?

#### Как рассуждать и алгоритм

Пока баланс меньше цели, увеличивайте баланс и счётчик недель. Шаг накопления должен быть положительным.

#### Решение

```python
balance = 1000
target = 4000
weeks = 0
while balance < target:
    balance += 700
    weeks += 1
print(weeks, balance)
```

#### Проверка

Получится `5 4500`. Для цели 1000 — `0 1000`; ровно достигнутая цель не требует лишней недели.

## Самостоятельная практика

Рассчитайте сумму, число и среднее значение положительных продаж. Если продаж нет, выведите «Нет данных». Проверьте [100, 200], [0, -1] и пустой список.
