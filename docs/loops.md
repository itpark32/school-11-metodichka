# 3. Циклы

<p class="reading-time">Чтение: 4 минуты</p>

Цикл повторяет действие. `while` выбирают, когда повторение зависит от условия, а `for` — когда нужно пройти по диапазону или коллекции.

!!! abstract "Фокус"
    - **Нужно знать:** `while`, `for`, `range`, счетчик, накопитель и условие остановки.
    - **Часто в работе:** `break`, `continue`, перебор коллекции и вложенные циклы.
    - **Достаточно узнавать:** бесконечный цикл с осознанным выходом через `break`.

## `while`: повторять до результата

```python
secret = 7
answer = 0
tries = 0

while answer != secret:
    answer = int(input("Угадайте число: "))
    tries += 1

print("Попыток:", tries)
```

Внутри цикла должно меняться значение, от которого зависит условие. Иначе цикл не закончится. В игре «Угадай число» внешний `while` отвечает за повтор игры, а внутренний — за попытки до правильного ответа.

## `for`, `range`, `break`, `continue`

```python
total = 0

for number in range(1, 11):
    if number == 5:
        continue
    if total > 25:
        break
    total += number
```

Правая граница `range()` не входит в диапазон. `continue` пропускает остаток текущей итерации, `break` завершает весь ближайший цикл.

## Вложенные циклы

```python
for row in range(3):
    for column in range(3):
        print(f"({row}, {column})", end=" ")
    print()
```

Внешний цикл меняет строку, внутренний — столбец. Эта схема позже создаёт и выводит игровое поле.
