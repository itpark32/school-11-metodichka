# Файлы, JSON, CSV и обработка ошибок

<p class="reading-time">Примерное время · Чтение: 5–7 мин · Практика: 45–75 мин</p>

!!! abstract "Фокус"
    - **Нужно знать:** `with`, режимы файлов, UTF-8, `try`, конкретный `except`.
    - **Нужно уметь:** сохранять данные и отличать отсутствие файла от его повреждения.

## Теория

Список в памяти исчезает после завершения программы. Файл позволяет восстановить данные при следующем запуске. Сначала договоритесь о формате: одна запись на строку, CSV-таблица или JSON со списками и словарями.

### Открытие и закрытие

```python
with open("report.txt", "w", encoding="utf-8") as file:
    file.write("Выручка: 1500\n")
```

`r` читает существующий файл, `w` создаёт или очищает файл, `a` дописывает в конец. `with` закрывает ресурс и при исключении. Относительный путь считается от рабочей папки запуска, а не обязательно от папки скрипта.

Для CSV используйте `csv.DictReader` и `csv.DictWriter`, открывая файл с `newline=""`. Они корректно обрабатывают разделители и кавычки внутри поля. Для JSON используйте `json.load` и `json.dump`; `ensure_ascii=False` сохраняет русский текст читаемым, `indent=2` задаёт отступы.

### Ожидаемая проблема и ошибка кода

`ValueError` возникает при `int("abc")`, `FileNotFoundError` — при чтении отсутствующего файла, `json.JSONDecodeError` — при неверном JSON. Ловите только то, на что умеете осмысленно ответить.

`else` после `try` выполняется без исключения; `finally` — при выходе из блока независимо от исхода. Не заворачивайте всё приложение в `except Exception: pass`: ошибка исчезнет из виду, а пользователь может получить ложное сообщение об успехе.

### Целостность данных

Отсутствующий файл на первом запуске может означать пустое хранилище. Повреждённый существующий файл — другая ситуация: нельзя молча заменить его пустым списком и затем перезаписать. Покажите ошибку и сохраните исходный файл для восстановления. Для надёжной записи применяют временный файл и замену, а для нескольких одновременных пользователей переходят к базе данных.

## Частые ошибки

Не путайте пустой файл с пустым JSON-списком `[]`. `with` гарантирует закрытие, но сам по себе не защищает от частичной записи. Не сообщайте «Сохранено» после неуспешной записи.

## Разбор практических задач

### Задача 1. Запись отчёта

#### Условие

Сохраните две строки отчёта в UTF-8.

#### Как рассуждать и алгоритм

Откройте файл для записи и добавьте переводы строк явно.

#### Решение

```python
lines = ["Заказов: 3", "Выручка: 1500"]
with open("report.txt", "w", encoding="utf-8") as file:
    for line in lines:
        file.write(line + "\n")
```

#### Проверка

Откройте report.txt: две строки на русском. Повторный запуск заменяет отчёт, а не добавляет ещё две строки.

### Задача 2. Безопасный ввод количества

#### Условие

Сделайте функцию преобразования строки в положительное целое. Для ошибки верните None.

#### Как рассуждать и алгоритм

Сначала обработайте неверный формат, затем проверьте диапазон.

#### Решение

```python
def parse_quantity(text):
    try:
        quantity = int(text)
    except ValueError:
        return None
    if quantity <= 0:
        return None
    return quantity
print(parse_quantity("3"), parse_quantity("abc"))
```

#### Проверка

3 → 3; abc, 0 и -2 → None. Строка "2.5" тоже отклоняется.

### Задача 3. Каталог в JSON

#### Условие

Сохраните каталог и прочитайте обратно, не собирая JSON вручную.

#### Как рассуждать и алгоритм

Используйте стандартный модуль и отдельные контексты чтения и записи.

#### Решение

```python
import json
products = [{"sku": "A", "name": "Чай", "stock": 3}]
with open("products.json", "w", encoding="utf-8") as file:
    json.dump(products, file, ensure_ascii=False, indent=2)
with open("products.json", encoding="utf-8") as file:
    restored = json.load(file)
print(restored == products)
```

#### Проверка

Будет True. Отдельно попробуйте загрузить файл с текстом {bad}: должна возникнуть JSONDecodeError, которую интерфейс сообщает пользователю без перезаписи файла.

## Самостоятельная практика

Выгрузите CSV «артикул;название;остаток». Включите название с точкой с запятой. Прочитайте файл обратно через csv и проверьте количество строк. Для неверного остатка укажите номер проблемной строки.
