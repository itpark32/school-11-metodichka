# 10. Сохранение и загрузка данных

<p class="reading-time">Чтение: 4 минуты</p>

Память списка исчезает после завершения программы. Чтобы каталог пережил перезапуск, объекты преобразуют в согласованный формат файла и затем восстанавливают.

## Сериализация

Пусть одна строка хранит один товар, а поля разделены `|`:

```python
def product_to_line(product):
    return "|".join([
        str(product.id),
        product.name,
        product.category,
        str(product.price),
        str(product.rating),
        str(product.amount),
    ])
```

При загрузке выполняется обратное преобразование: `split()`, проверка числа полей, преобразование типов и создание `Product`.

## Два формата — две цели

- служебный файл обязан надёжно восстановить все поля и последний выданный ID;
- печатный файл должен быть удобен человеку и не обязан загружаться обратно.

Не смешивайте их. Красивое выравнивание пробелами удобно читать, но ненадёжно разбирать программой.

## Безопасная запись

```python
try:
    with open(filename, "w", encoding="utf-8") as file:
        for product in products:
            file.write(product_to_line(product) + "\n")
except OSError:
    return False
return True
```

Преобразования при загрузке тоже могут завершиться ошибкой. UI должен получить понятный результат, а не продолжать работу с частично загруженным каталогом.
