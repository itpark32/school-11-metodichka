# Сериализация, загрузка и служебный формат файла

!!! abstract "Фокус"

    - **Нужно уметь:** загрузить каталог полностью либо сообщить об ошибке без потери старых данных.

## Теория

Файл должен сохранять все данные, необходимые для восстановления. Таблица с красивыми пробелами удобна человеку, но не обязательно пригодна для загрузки. Разделяйте служебный формат и печатный экспорт.

### Договор формата

В занятиях использовался строковый формат с разделителями и отдельно сохранённым последним ID. Он требует правил: что означает поле, какие символы запрещены в названии, как записана дата. Если разделитель может встретиться внутри значения, простой split перестаёт быть надёжным — нужен CSV с экранированием либо JSON.

В учебном JSON удобно хранить объект с двумя полями: last_id и items. Последний выданный ID может быть больше максимального ID оставшихся записей после удаления. Его нельзя уменьшать при загрузке.

### Объект → словарь → текст

```python
from dataclasses import dataclass, asdict
from datetime import date

@dataclass
class Product:
    id: int
    name: str
    released: date

product = Product(7, "Чай", date(2026, 11, 1))
row = asdict(product)
row["released"] = product.released.isoformat()
```

Asdict не превращает дату в JSON автоматически. Для чтения выполните обратное date.fromisoformat. Числа также должны восстановиться числами, а не остаться строками для красивого вывода.

### Проверка до замены

Загрузите файл во временный список. Проверьте поля, типы, ID, уникальность и диапазоны. Только после проверки всего документа заменяйте действующий каталог. Ошибка одной записи не должна стирать прежнюю рабочую коллекцию.

### Первый запуск и повреждение

Отсутствие файла может означать первый запуск с пустым каталогом. Существующий повреждённый файл — другая ситуация: сохраните его для исправления, покажите причину и не перезаписывайте автоматически пустым списком.

### Запись и замена

Режим w сразу очищает старый файл. Для снижения риска частичной записи сначала подготовьте временный файл рядом с основным, затем замените основной через Path.replace. Это не заменяет резервную копию и не решает одновременную запись нескольких процессов. Для курса работаем с одним процессом-владельцем файла.

## Частые ошибки

Не выдавайте ошибку чтения за пустой каталог. Не используйте repr как формат. Не теряйте тип даты и последний ID. Не обещайте защиту от всех сбоев одним with.

## Разбор практических задач

Сначала запишите свой план и ожидаемый результат, затем сравните с разбором.

### Задача 1. Сохранение JSON

#### Условие

Сохраните служебное состояние с последним ID.

#### Как рассуждать и алгоритм

Используйте json.dump, а не ручную склейку кавычек.

#### Решение

```python
import json
state = {"last_id": 9, "items": [{"id": 7, "name": "Чай"}]}
with open("catalog.json", "w", encoding="utf-8") as file:
    json.dump(state, file, ensure_ascii=False, indent=2)
```

#### Проверка

После чтения last_id=9, даже если в каталоге только запись 7.

### Задача 2. Уникальность ID

#### Условие

Отклоните каталог с повторяющимся положительным ID.

#### Как рассуждать и алгоритм

Проверяйте структуру списка перед сменой действующих данных.

#### Решение

```python
def validate_ids(items):
    seen = set()
    for item in items:
        value = item["id"]
        if type(value) is not int or value <= 0 or value in seen:
            raise ValueError("Неверный или повторный ID")
        seen.add(value)
validate_ids([{"id": 1}, {"id": 2}])
```

#### Проверка

ID 1 и 2 принимаются, повтор 1 отклоняется. Это проверка ID, остальные поля проверяются отдельно.

### Задача 3. Подготовленная замена

#### Условие

Запишите состояние через временный файл в той же папке.

#### Как рассуждать и алгоритм

Основной файл заменяется после успешной записи временного. Ошибку не скрывайте.

#### Решение

```python
import json
from pathlib import Path

def save_state(path, state):
    path = Path(path)
    temporary = path.with_name(path.name + ".tmp")
    with temporary.open("w", encoding="utf-8") as file:
        json.dump(state, file, ensure_ascii=False, indent=2)
    temporary.replace(path)
```

#### Проверка

Сохраните и прочитайте состояние. Если запись временного файла не удалась, replace не выполняется. Функция рассчитана на одного писателя.

## Самостоятельная практика

Сохраните и восстановите каталог услуг с датами и ID. Проверьте пустой каталог, неизвестный формат, повтор ID и неверную дату. При ошибке исходный список в памяти и исходный файл должны остаться доступными.
