# Методичка 11 потока IT-ПАРКа

30 учебных тем, 90 задач с разборами и 12 самостоятельных брифов. Маршрут: основы Python → функции и состояние → консольный CRUD → файлы и внешние данные → Telegram, FSM, Docker → проектирование и защита.

Формат согласован с `school-10-metodichka`: теория, частые ошибки, три разобранные задачи, самостоятельная практика и вопросы. Общие главы перенесены и адаптированы. Каждый раздел раскрывает понятия; проекты служат примерами применения.

## Локальный запуск

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-docs.txt
mkdocs serve
```

В Windows активируйте `.venv\Scripts\activate`. Сайт доступен на http://127.0.0.1:8000.

## Проверка

```bash
python scripts/update_reading_times.py
python scripts/check_content.py
mkdocs build --strict
```

Подписи чтения рассчитываются по всему тексту и коду статьи: 110–160 слов либо 10–18 непустых строк кода в минуту. Это диапазоны для повторения, не замеры учеников. Время практики оценивается отдельно по заданиям. Проверка содержания обнаруживает устаревшие подписи, неверную структуру, локальные ссылки и ошибки синтаксиса Python.

## Публикация

Существующий GitHub Actions workflow собирает и публикует сайт при push в main. Он проверяет содержание до строгой сборки. Сгенерированные файлы site/ не входят в Git.

## Проверка разобранных примеров

```bash
python -m unittest discover -s tests -v
```

Проверки используют функции из текста статей: CRUD, сохранение, даты, рекурсию, фильтры, генератор, HTML и контекст FSM. Для HTML/FSM установите beautifulsoup4 и pyTelegramBotAPI; без них соответствующие проверки помечаются пропущенными. Сеть и действующий токен не нужны. Примеры FSM проверены с pyTelegramBotAPI 4.32.0.
