# Методичка 11 потока для школьников

17 коротких глав для повторения Python: от ввода и циклов до `dataclass`, CRUD, файлового хранения и большого консольного проекта. В каждой главе есть приоритеты, понятные примеры, мини-практика и вопросы для самопроверки.

## Локальный запуск

```bash
python -m pip install -r requirements-docs.txt
mkdocs serve
```

Сайт откроется по адресу `http://127.0.0.1:8000`.

## Проверка и публикация

```bash
mkdocs build --strict
```

Каждый push в ветку `main` запускает GitHub Actions и публикует собранный сайт в GitHub Pages.
